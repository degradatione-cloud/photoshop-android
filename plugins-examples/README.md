# Плагины эффектов

Плагин — обычный `.json`. Кладётся в приложении: «Эффекты» → «Импорт плагина».

Поля (все необязательные, кроме имени):

| поле | смысл | диапазон |
|---|---|---|
| `name` | подпись на превью | строка |
| `brightness` | яркость | −100…100 |
| `contrast` | контраст | −100…100 |
| `saturation` | насыщенность | 0…3 |
| `temperature` | тепло/холод | −100…100 |
| `vignette` | затемнение краёв | 0…1 |
| `grain` | зерно | 0…1 |
| `fade` | выцветание | 0…1 |
| `duotoneA` / `duotoneB` | две точки градиента | `#RRGGBB` |

Файлы сохраняются в `files/plugins/`, приложение подхватывает их при старте.
