> **Небольшой проект для портирования.** Порт интерфейса Adobe Photoshop на Android:
> Compose + собственное растровое ядро, PSD-парсер/писатель на Rust (PhotoCraft) через JNI.
> Всё считается на телефоне, ничего не уезжает в облако.

# Photoshop для Android (клон интерфейса)

[Последний релиз](https://github.com/degradatione-cloud/photoshop-android/releases/latest) · `com.degradatione.psandroid` · Android 15+ (API 35)

Настоящий Adobe Photoshop портировать нельзя — закрытый бинарь под x86/ARM-десктоп, миллионы строк, лицензия.
Это рабочая альтернатива с **тем же интерфейсом**: панели, тулбар с шорткатами, слои, режимы наложения,
история, коррекции — и всё это реально редактирует пиксели на телефоне.

## Что работает

- Слои: добавить / дублировать / удалить / порядок / видимость / непрозрачность
- Режимы наложения: Normal, Multiply, Screen, Overlay, Darken, Lighten, Linear Dodge, Difference
- Инструменты (шорткаты как в PS): V рука, B кисть, E ластик, G заливка, I пипетка, C кадрирование, T текст, Z масштаб
- Кисть с размером, цветом, ластик с настоящим CLEAR-стиранием (прозрачность)
- Заливка flood fill с допуском, пипетка, текст с размером и цветом
- Коррекции: яркость/контраст, насыщенность, ч/б, инверсия, размытие
- Кадрирование рамкой по холсту
- История: отмена/повтор (6 шагов, включая штрихи кисти)
- Экспорт: PNG в галерею (`Pictures/Photoshop`) или «Поделиться»
- Открытие любого изображения из галереи (SAF picker), автоподгон под 1600 px
- Автообновление APK из GitHub Releases

## Формат

- Один документ, до 1600 px по длинной стороне, ARGB_8888.
- Шрифты — системные (в Adobe Clean лицензия не влезет), остальная типографика/палитра — из CC-темы.
